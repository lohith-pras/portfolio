# Inspiration board

Every reference pasted during the redesign lands here, with what to take from it and where it goes.
Working mockup: `mockups/v3.html` (combines everything below). Earlier: `mockups/signal-to-silicon.html`.

## Direction so far

- Black page, grey text, **one accent used only for what is live or selected**.
- Positioning: "From signal to silicon": embedded → RF data → radar/MIMO (ISAC) → neuromorphic (Fraunhofer, AKD1500).
- Proof is measurements and real hardware, not mockups or AI renders.
- Introduce the person first, details after.
- Visual language: exploded, isometric and anatomy views of hardware and systems, with callouts.
- Theme: Setience (black, cream, red accent) with Intown navy `#21304e` for project cards.
- Range is shown as a coverage map (projects × layers), not the isometric stack; exploded views live on project pages.
- Accent: muted, not neon (slate blue default). Two refs use orange-red, but only on one element.
