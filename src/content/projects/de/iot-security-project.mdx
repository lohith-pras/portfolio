# IoT-Sicherheitsprojekt

Absicherung von Smart-Home-Geräten gegen externe Angriffe und unbefugten Netzwerkzugriff.

## Phase 1
Bedrohungsmodellierung und Analyse der Angriffsvektoren in einer IoT-Heimnetzwerktopologie.

## Phase 2
Penetrationstests und automatisierter Schwachstellenscan der eingebetteten Gerätefirmware.

## Phase 3
Entwicklung von Eindämmungsmaßnahmen und Erstellung des abschließenden Sicherheitsberichts.
